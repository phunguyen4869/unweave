What it does

Unweave packages Sound Razor into a native desktop app (Windows installer; Linux and macOS install scripts) with a polished UI. Drop in a track (or paste a YouTube link) and it separates the mix into individual instrument stems using AI models such as Demucs, MDX-Net, and RoFormer — all processed locally, nothing uploaded.

🖥️

Native desktop app

Runs in its own window, no browser required, with a modern, redesigned interface.

🔒

100% local processing

All AI models run on your computer. No cloud uploads, no accounts, no API keys.

🎸

Guitar splitting

Go further than vocals/drums/bass — separate lead and rhythm guitar parts too.

📺

YouTube import

Paste a YouTube link to download and separate audio directly, no extra tools needed.

🎚️

Real-time mixer

Volume, mute, and solo each stem independently while you play back the track.

🎵

Format support

WAV, MP3, FLAC, M4A, OGG, AAC and more, plus project management for your separated tracks.

Getting started

On Windows the installer is tiny and works offline. On Linux and macOS use the install scripts in the repo. First launch asks you to confirm a one-time download of the rest.

1
Install the app.

Windows: download the setup exe (Program Files; admin prompt; optional desktop icon). Linux: ./installer/install-linux.sh. macOS: ./installer/install-macos.sh (unsigned .app — right-click → Open once).

2
Approve the one-time setup.

On first launch the app window opens immediately and asks you to consent to downloading FFmpeg and the PyTorch/audio-separation stack (~1.6 GB total).

3
Import a track and separate.

AI models (~500 MB) download automatically on your first separation. After that, everything runs offline.

System requirements

  • OS: Windows 10/11 (64-bit); also Linux (x86-64) and macOS via install scripts
  • RAM: 8 GB minimum, 16 GB recommended
  • Storage: ~10 GB free space (for dependencies and models)
  • CPU: Modern 64-bit processor (4+ cores recommended)
  • GPU: Optional — CPU works fine
